# Этап 5. Дополнительные команды (mv, cp)

Команды, изменяющие VFS. Изменения происходят **только в памяти** — CSV-файл на диске не меняется.

| Команда | Что делает |
|---|---|
| `cp [-r] источник... приёмник` | копирует; без `-r` папки не копируются; копия независима от оригинала |
| `mv источник... приёмник` | переносит или переименовывает |

Правила (как в UNIX): если приёмник — существующая папка, источники кладутся внутрь; иначе приёмник — новое имя.
Несколько источников допустимы только если приёмник — папка. Файл-приёмник перезаписывается.
Если текущая папка была перемещена, `cwd` сбрасывается в `/`.

Ошибки: нет источника/операнда, источник не найден, папка без `-r`, копирование папки в саму себя,
одинаковые источник и приёмник, нет родительской папки, перезапись папки, папка поверх файла, перемещение `/`, неверная опция.

## Запуск
```bash
python3 emulator.py --vfs vfs/deep.csv --script scripts/ok.emu
```
`scripts/ok.emu` — все режимы `cp` и `mv` вместе с остальными командами (`vfs-tree`, `ls`, `du`), `scripts/err_*.emu` — ошибки.

## Тесты (скрипты реальной ОС)

В папке `tests/` лежат пары `test_*.sh` (Linux/macOS/Git Bash) и `test_*.bat` (Windows).
Они запускают эмулятор в консольном режиме `--headless`, поэтому выполняются без окна.

```bash
sh tests/run_all.sh        # Linux / macOS / Git Bash
tests\run_all.bat          # Windows
```

Чтобы увидеть то же самое **в окне GUI**, запустите вручную без `--headless`, например:
`python3 emulator.py --vfs vfs/deep.csv --script scripts/ok.emu`
