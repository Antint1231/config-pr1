# Этап 4. Основные команды

Реализована логика `ls` и `cd`, добавлены `tail`, `uname`, `du`. Все команды работают с VFS в памяти.

| Команда | Режимы |
|---|---|
| `ls [-l] [-a] [путь...]` | `-l` — подробно (тип, размер), `-a` — скрытые файлы (`.name`), несколько путей, файл вместо папки |
| `cd [путь]` | относительный/абсолютный путь, `..`, `.`, без аргумента — в `/`; приглашение показывает текущую папку |
| `tail [-n N] файл...` | по умолчанию 10 строк, `-n N`, несколько файлов (с заголовками `==> имя <==`) |
| `uname [-s -n -r -v -m -o -a]` | без флагов = `-s`; `-a` — всё; флаги можно комбинировать |
| `du [-s] [-h] [путь...]` | размер всех вложенных папок; `-s` — только итог; `-h` — K/M/G |

Обрабатываемые ошибки: нет такого пути, `cd` в файл, лишние аргументы, неверная опция, `tail` бинарного файла или папки,
неверное `-n`, нет операнда и т.д.

## Запуск
```bash
python3 emulator.py --vfs vfs/deep.csv --script scripts/ok.emu
```
`scripts/ok.emu` — стартовый скрипт со всеми режимами всех команд; `scripts/err_*.emu` — по одной ошибке на файл
(скрипт останавливается на первой ошибке, поэтому ошибки вынесены в отдельные файлы).

## Тесты (скрипты реальной ОС)

В папке `tests/` лежат пары `test_*.sh` (Linux/macOS/Git Bash) и `test_*.bat` (Windows).
Они запускают эмулятор в консольном режиме `--headless`, поэтому выполняются без окна.

```bash
sh tests/run_all.sh        # Linux / macOS / Git Bash
tests\run_all.bat          # Windows
```

Чтобы увидеть то же самое **в окне GUI**, запустите вручную без `--headless`, например:
`python3 emulator.py --vfs vfs/deep.csv --script scripts/ok.emu`
