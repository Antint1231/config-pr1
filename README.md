# Этап 3. VFS

Подключена виртуальная файловая система, загружаемая из CSV. Всё хранится **только в памяти**.

## Формат CSV
```csv
path,type,content
/docs,dir,
/docs/hello.txt,file,SGVsbG8h
/docs/a/b/c.bin,file,AP+AgAcB
```
- `path` — абсолютный путь. **Вложенность задаётся самим путём** — это самый простой способ хранить дерево в плоской таблице.
  Недостающие родительские папки создаются автоматически.
- `type` — `dir` или `file`.
- `content` — содержимое файла в **base64** (подходит и для текста, и для двоичных данных); у папок пусто.

Закодировать текст: `echo -n "Hello!" | base64`.

## Ошибки загрузки (сообщаются в stderr и в окне, код выхода 1)
файл не найден · неверный заголовок · не 3 колонки · неизвестный type · неверный base64 · дубликат пути · пустой файл.

## Команды
`ls`, `cd` (пока заглушки), `exit`, `conf-dump`, и служебная `vfs-tree` — печатает всё дерево VFS.

## Варианты VFS (`vfs/`)
`minimal.csv` (один файл) · `several.csv` (несколько файлов, бинарный файл, папки) · `deep.csv` (4 уровня вложенности) · `bad/` (некорректные файлы).

## Тесты (скрипты реальной ОС)

В папке `tests/` лежат пары `test_*.sh` (Linux/macOS/Git Bash) и `test_*.bat` (Windows).
Они запускают эмулятор в консольном режиме `--headless`, поэтому выполняются без окна.

```bash
sh tests/run_all.sh        # Linux / macOS / Git Bash
tests\run_all.bat          # Windows
```

Чтобы увидеть то же самое **в окне GUI**, запустите вручную без `--headless`, например:
`python3 emulator.py --vfs vfs/deep.csv --script scripts/all.emu`

Стартовый скрипт `scripts/all.emu` проверяет все команды этапов 1-3 (в конце — ошибка, на которой скрипт останавливается).
